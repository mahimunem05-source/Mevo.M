# Mahi Music — Developer Notes

This project is maintained and developed by Munem Mahi.

## About

Mahi Music is a premium music streaming web application built with React,
TanStack Start, and Tailwind CSS — featuring immersive playback, curated
music rows, and a Spotify-inspired dark UI.

## Features

- Real-time search across songs, artists, albums, and genres
- Section-aware queue with auto-play
- Persistent bottom player with full playback controls
- Curated rows: Bangla Beats, Mahi's Favourite, Soft Hindi Vibes, Global Tracks
- Download support for tracks
- Fully responsive across desktop, tablet, and mobile

## Tech Stack

- React + TanStack Start
- Tailwind CSS
- Framer Motion
- Lucide Icons
