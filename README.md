# Mahi Music

A premium music streaming web application built with React, Tailwind CSS, and Framer Motion — offering a Spotify/Apple Music-level experience with smooth animations, glassmorphism design, and immersive sound streaming.

## Features

- Real-time search across songs, artists, albums, and genres
- Section-aware queue and auto-play
- Persistent bottom player with full playback controls
- Curated rows: Bangla Beats, Mahi's Favourite, Soft Hindi Vibes, Global Tracks
- Download support for tracks
- Fully responsive across desktop, tablet, and mobile
- Dark theme with premium glassmorphism UI

## Tech Stack

- React
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Getting Started

Requires Node.js and npm/bun installed.

\`\`\`sh
git clone <this-repository-url>
cd mahi-music
npm i
npm run dev
\`\`\`
